# 文字星球 (Blogverse) - 全功能现代博客与创作平台

一款以优雅阅读、轻量创作与全平台响应式为核心的高颜值现代博客系统。原生适配移动端手势与桌面端大屏体验。

---

## ✨ 核心特色功能

1. **🎨 10 种独具美感的结构设计风格（非单调调色，多维视觉美学）**
   - **宣纸墨韵**：宋瓷书简、古典文人雅韵、温润边框与雅致衬线；
   - **瑞士包豪斯**：极简纯粹、粗黑边框、直角结构与高对比现代感；
   - **赛博霓虹**：黑金未来、霓虹青蓝发光阴影与等宽科技排版；
   - **复古打字机**：机械打字机虚线质感、怀旧米黄复古纸张；
   - **北欧莫兰迪**：低饱和度、大圆角温润克制、极简生活格调；
   - **极夜纯黑**：OLED 纯黑深邃、蓝天极光微光、极致夜间省电；
   - **森林原木**：质朴苔藓木香、微绿护眼底色、自然清新；
   - **日系胶片**：复古柯达暖色、柔和颗粒质感；
   - **商务藏青**：深海沉着蓝调、现代精英商务气质；
   - **梦幻极光**：彩云霓裳渐变紫、流动通透美感。

2. **🌐 丰富的多语言支持（自由即时切换）**
   - 完备支持 **简体中文 (zh-CN)**、**繁體中文 (zh-TW)**、**English (en-US)** 与 **日本語 (ja-JP)**。
   - 所有页面标题、按键、弹窗、提示信息与操作按钮均已实现全量精细本地化。

3. **☁️ 完整云端双向同步（Cloudflare D1 + R2 + KV）**
   - 不仅是文章，**用户自定义头像、全局背景壁纸、站点名称、语言偏好与多图配图** 均可完整同步至 Cloudflare D1 分布式 SQL 数据库与 KV。
   - 配套高清晰度图片上传与 R2 永久对象存储支持，多设备访问无缝漫游。

4. **📖 独家深度架构专栏文章**
   - 内置精心撰写的技术指引篇章：《**Cloudflare D1（数据库）、R2（图片存储桶）与 KV 的对接规范、绑定变量说明及扩展指南**》，在应用内即可一键研读全套 Serverless 架构设计。

5. **⏰ 全球实时网络跳秒时钟**
   - 搭载精准世界时区转换器，支持北京、东京、新加坡、伦敦、巴黎、纽约、洛杉矶、悉尼等 8 大核心时区一秒切换。

6. **🔐 管理员身份鉴权体系**
   - 支持环境变量 `PASSWORD` 配置（默认 `123456`）；
   - 访客安全只读（可阅读、点赞、收藏）；
   - 管理员登录解锁发布、草稿箱管理、二次修改编辑与安全删除功能；
   - 支持在个人设置中动态修改并持久化管理员新密码。

## 🔑 环境变量说明

| 变量名称 | 默认值 | 作用说明 |
| :--- | :---: | :--- |
| **`PASSWORD`** | `123456` | **管理员登录口令**。在部署平台添加后，直接使用此密码登录并管理博客。 |
| `EXPO_PUBLIC_PASSWORD` | `123456` | 兼容变量名，作用同 `PASSWORD`。 |
| `EXPO_BASE_URL` | 留空 | 子路径部署参数（如 GitHub Pages 填写 `/仓库名`；根目录部署留空）。 |

## 🚀 多平台部署指南

本项目支持一键部署到主流云厂商与私有服务器，详细操作步骤请查阅 **[完整多平台部署指南 (DEPLOYMENT.md)](DEPLOYMENT.md)**：

- **Cloudflare Pages**：连接 GitHub 即可实现 Git 持续交付，零成本接入 D1 数据库、R2 存储桶与 KV。
- **腾讯云 (EdgeOne / COS)**：支持腾讯云 EdgeOne 静态站点托管与 COS 对象存储全球 CDN 加速。
- **阿里云 (ESA / OSS)**：支持阿里云边缘安全加速与 OSS 静态页面托管。
- **Docker 容器化**：仓库内置轻量高并发 Nginx 多阶段构建 Dockerfile，一条命令完成镜像构建与生产启动。
- **Linux VPS / 独立服务器**：提供生产级 Nginx 与 Caddy 反向代理、Gzip 压缩与 HTTPS 自动签发配置。

## 💻 本地运行与开发

```bash
# 1. 安装项目依赖
pnpm install

# 2. 启动本地开发服务（8081 端口）
pnpm dev

# 3. 完整代码质量检查
pnpm check   # TypeScript 类型检查
pnpm lint    # ESLint 代码风格扫描
pnpm test    # Vitest 自动化单元测试
pnpm build:web # 导出静态 Web 站点到 dist/
```
